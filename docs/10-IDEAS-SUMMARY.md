## Lessons Learned

| Lesson                                                               | Date    |
| -------------------------------------------------------------------- | ------- |
| Next.js App Router is powerful but needs careful SSR/CSR split       | 2026-07 |
| framer-motion adds bundle weight — use CSS animations where possible | 2026-07 |
| API-generated images are slow — use next/image instead               | 2026-07 |
| Gemini API works well for chatbot — better than OpenAI for cost      | 2026-07 |
| Tailwind CSS 4 is much faster to build with                          | 2026-07 |
