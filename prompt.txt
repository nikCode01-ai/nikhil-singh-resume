Act as a Senior Full Stack Performance Engineer and Next.js Optimization Specialist.

Analyze the entire portfolio project and fix ALL performance, accessibility, best practices, and SEO issues.

CONSTRAINTS
- Do NOT break existing functionality or business logic.

==================================================
PERFORMANCE
==================================================

Fix all performance issues:

- Eliminate render-blocking resources (CSS, JS, fonts).
- Reduce JavaScript execution time and unused JS.
- Tree-shake unused imports, remove dead code.
- Dynamic import heavy components, lazy load below-the-fold content.
- Lazy load images, videos, and third-party widgets.
- Optimize hydration, convert to Server Components where possible.
- Reduce main-thread work, TBT, FCP, and improve LCP and INP.
- Fix all layout shifts: add width/height to images, use aspect-ratio.
- Optimize fonts: preload critical, drop unused weights, use font-display: swap.
- Compress images to WebP/AVIF, optimize SVGs, preload hero image.
- Use responsive images with next/image properly configured.
- Reduce DOM size, remove duplicate components.
- Minimize and purge unused CSS/Tailwind utilities.
- Memoize expensive calculations, optimize useEffect and state updates.
- Deduplicate and cache API calls, enable ISR/SSG where possible.
- Add cache headers, enable Brotli/Gzip, optimize network payload.
