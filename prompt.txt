You are a Senior Full-Stack Performance Engineer and Next.js optimization specialist.
Analyze this portfolio project and fix ALL Lighthouse audits, performance bottlenecks, accessibility issues, best practice violations, and SEO problems.

RULES
- Do NOT break existing functionality, business logic, or APIs.
- Preserve all routes, backward compatibility, and pixel-perfect UI.
- Fix every audit item across Passed Audits, Diagnostics, Opportunities, Insights, and Hidden sections.
- Verify the app builds and works after every optimization.

==================================================
PERFORMANCE TARGETS
==================================================

Metrics: Performance 100 | LCP < 2.5s | CLS < 0.1 | INP < 200ms | TBT < 150ms | FCP < 1.5s | Speed Index < 2s | TTFB < 800ms

==================================================
CRITICAL REQUEST CHAIN & RESOURCES
==================================================

- Eliminate render-blocking CSS/JS/fonts.
- Reduce network dependency chain and critical request chains.
- Preconnect third-party origins, DNS-prefetch external domains.
- Preload critical resources, prefetch next page resources.
- Remove unnecessary redirects, reduce TTFB.
- Remove unused CSS/JS, tree-shake dead code.
- Minify HTML/CSS/JS, compress SVGs.
- Replace PNG/JPG with AVIF/WebP, resize oversized images.
- Use proper responsive srcset, lazy load all below-the-fold media.

==================================================
CACHING & CDN
==================================================

- Serve static assets with long cache lifetime + immutable caching.
- Optimize Cache-Control headers, configure ETag correctly.
- Enable CDN caching, prevent unnecessary revalidation.

==================================================
THIRD-PARTY SCRIPTS
==================================================

Audit every third-party resource (Analytics, GTM, Fonts, Chat Widget, etc.):
- Load only when needed, use async/defer.
- Lazy load non-critical scripts, remove duplicates.
- Reduce execution time and main-thread cost.

==================================================
CORE WEB VITALS
==================================================

LCP: Preload LCP image, compress, remove blocking CSS/JS, priority loading.
CLS: Add fixed image dimensions, reserve component space, optimize fonts, use skeleton loaders.
INP: Fix long tasks, heavy click handlers, expensive event listeners, large React renders.
Main Thread: Reduce parse/compile time, script evaluation, style calculation, layout, paint.

==================================================
BUNDLE & MEMORY
==================================================

- Analyze bundle: find largest JS bundles, duplicate packages, heavy libraries.
- Replace heavy packages with lightweight alternatives.
- Fix memory leaks: detached DOM nodes, unremoved listeners, uncleaned intervals/timers, stale state.

==================================================
NEXT.JS SPECIFIC
==================================================

- Replace all <img> with next/image, configure sizes/priority/placeholder/quality/formats.
- Use next/font, remove duplicate/unused font weights, self-host, font-display: swap.
- Optimize Server Components vs Client Components, use dynamic imports with ssr: false for heavy client components.
- Configure next.config.js: images, webpack, headers, caching, ISR/SSG where possible.
